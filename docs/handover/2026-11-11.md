## 关键决策

- 纯 JavaScript，不引入 TypeScript 和打包器（新手起步最简）
- Electron 用国内镜像（npmmirror）安装，版本 33.4.11
- Monaco 用 AMD loader 接入（无打包器方案）
- IPC 用 contextBridge + ipcMain.handle，contextIsolation=true 保持安全
- 编译器内置到 `tools/mingw64`（项目自包含，findGcc 优先找这里，已 gitignore）

## ⚠️ 重要踩坑：ELECTRON_RUN_AS_NODE=1

- **现象**：`npm start` 报 `app.whenReady is not a function`，`require('electron')` 返回路径字符串而非 API
- **根因**：WorkBuddy（Electron 应用）向子进程注入 `ELECTRON_RUN_AS_NODE=1`，让 electron.exe 以纯 Node 模式运行
- **修复**：`start.js` 里 `delete process.env.ELECTRON_RUN_AS_NODE` 后再 spawn Electron
- **排查标志**：报错含 `app.whenReady` 报 undefined、`require('electron')` 返回 string 即为此问题
